# Ingestão de dados: AWS S3 - PostgreSQL

Projeto desenvolvido durante meus estudos de Engenharia de Dados, utilizando python para realizar a leitura de dados armazenados no Amazon S3 e inseri-los em uma tabela PostgreSQL hospedada no Amazon RDS.

## Arquitetura

AWS S3 -> Python -> Leitura e processamento de dados -> AWS RDS -> Tabela de destino

## Tecnologias utilizadas

- Python
- PostgreSQL
- AWS RDS
- AWS S3
- Boto3
- psycopg2
- python-dotenv
- Git
